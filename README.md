# cybersecurity-skills

网络安全技能合并仓库，供 WorkBuddy / Claude Code / Cursor 等 agentskills.io 兼容 Agent 使用。

## 组成

- `cybersecurity-kb/` 及 754 个防御/合规/取证技能 — 源自 ctkqiang/CybersecuritySkills（fork of mukul975/Anthropic-Cybersecurity-Skills），Apache-2.0
- `hack/` 及 102 个进攻/赏金/CTF 技能 — 源自 strivepan-svg/hack-skills（fork of yaklang/hack-skills），MIT
- `security-hub/` — 统一入口与合并索引

## 使用

- 防御/合规/取证：`cybersecurity-kb/SKILLS_INDEX.md`
- 进攻/赏金/CTF：从 `hack` 入口进入
- 统一路由：`security-hub/SECURITY_HUB_INDEX.md`
